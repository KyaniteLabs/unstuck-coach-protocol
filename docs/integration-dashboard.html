Dense HTML is now the review surface.

For multi-section decisions, plans, reports, queues, and strategy work, use full HTML/CSS with sticky navigation, compact summaries, tables, charts, timelines, matrices, and filterable detail. Markdown can remain the source layer; the human-facing decision artifact should usually be HTML.
